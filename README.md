# Mossy — versions

Mossy est un compagnon de bureau pour macOS : il vit en bas de l'écran, il a soif
après un moment d'activité continue, et il propose une pause courte. Il rappelle,
il ne bloque jamais.

**Téléchargement : [dernière version](https://github.com/Scra3/mossy-public/releases/latest)**

Ce dépôt ne contient pas le code — seulement `version.json`, que l'app interroge
pour savoir si elle est périmée, et les `.dmg` publiés en *releases*.

Aucun compte, aucune inscription, aucune donnée envoyée : votre programme, votre
historique et vos retours restent sur votre Mac.
